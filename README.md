## Description

Alzikrayat is a simple photo sharing application. Users can register, log in, upload photos, view photo details, and add comments.

## Technologies

React, React Router, Context API, localStorage, Node.js, Express, MySQL, mysql2, and Multer.

## Run locally

1. Start MySQL Server.
2. Run `schema.sql` in MySQL.
3. In `server`, run `npm install`, then set your database password and run `npm start`.
4. In another terminal, in `client`, run `npm install`, then `npm run dev`.
5. Open the Vite URL shown in the terminal.

The server uses MySQL on localhost with user `root` and database `alzikrayat` by default. Set `DB_PASSWORD` if your root account has a password. You can also set `DB_HOST`, `DB_USER`, and `DB_NAME`.
